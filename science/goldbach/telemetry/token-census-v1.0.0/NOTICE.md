# Publication notice

This package publishes aggregate telemetry, methodology, status, and hashes.
It intentionally excludes raw session logs, private correspondence, local
filesystem paths, credentials, account identifiers, hardware identifiers, and
the nine unavailable remote Windows ledgers.

The package is a workload and governance case study. It is not evidence of a
Goldbach proof, token savings, model superiority, energy use, cost, ROI,
productivity, or external peer review.

No public software licence is granted by this measurement package. Repository
licensing terms remain authoritative.
