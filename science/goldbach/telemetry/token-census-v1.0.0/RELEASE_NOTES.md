# Goldbach Token Census v1.0.0

This release publishes the evidence-bound local token census for the LIMEX
Goldbach research run from the first explicit Goldbach instruction through the
deployment of `goldbach-v1.8.767`.

## Headline result

```text
LOCAL_GOLDBACH_CLASSIFICATION_ENVELOPE = 4.800018574_TO_5.327048926_BILLION_TOKENS
GLOBAL_EXACT_TOTAL                     = NOT_IDENTIFIABLE
GLOBAL_GOLDBACH_STATUS                 = NO_PROOF
```

Nine visible remote Windows tasks lack locally accessible token ledgers. The
release performs no imputation and makes no energy, cost, ROI, efficiency, or
mathematical-completion claim.

## Included

- English methods, stack, business, and peer-review README;
- German human Goldstandard;
- machine-readable Goldstandard;
- independent audit summary;

- private raw JSONL telemetry;
- private messages and correspondence;
- local paths and device identifiers;
- unavailable remote-host ledgers;
- unmeasured energy, cost, and provider-infrastructure data.
