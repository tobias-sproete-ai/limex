# Security policy

Report suspected vulnerabilities through the repository host's private security-advisory channel. Do not publish exploit details in a public issue before coordinated review.

Please identify the affected release, file and function, attacker-controlled input, trust-boundary crossing, concrete impact, prerequisites, and a minimal reproduction when safe.

This candidate is a local reference implementation. Productive payment rails, wallets, blockchains, external providers, distributed consensus, embedded targets, hard real-time guarantees, and physical safety functions are outside its validated scope.
