# Scope and non-claims

## In scope

- deterministic event canonicalization and digest binding;
- idempotent settlement-state projection;
- append-only correction semantics;
- Merkle-root construction for bounded event batches;
- release-seal input validation, no-clobber persistence, and replay rejection;
- one-way, schema-bound execution-attestation input from an external language-model workflow;
- local tests, static source checks, cleanroom-content checks, and self-excluding package hashing.
- owner-only local state and ledger storage checks on macOS, including rejection of extended ALLOW ACLs;
- aggregate SHA-256 binding and application-level bounded work for tracked Git worktree bytes;
- commit-typed HEAD plus direct HEAD/index/raw-worktree comparison without repository-selected content-filter execution, replacement objects, lazy fetching, interactive prompts, credential helpers, or transports;
- descriptor-bound release-state operations with namespace-displacement rejection.

## Not established

- no productive payment, bank, wallet, blockchain, or treasury operation;
- no autonomous financial or release authority for a language model;
- no production deployment, cross-platform certification, or universal absence-of-defect claim;
- no cross-platform ACL or storage-boundary attestation; unsupported ACL platforms fail closed;
- no legal, regulatory, patentability, freedom-to-operate, tax, accounting, or safety conclusion;
- no guarantee of hard real-time behavior, distributed consensus, external-provider finality, or physical fault tolerance.
- no hard OS-level CPU, address-space, or descendant-process limit for the pinned Git child;
- no adversarially atomic multi-file snapshot on a concurrently writable filesystem; public release requires a separately attested immutable snapshot or read-only source;
- no independent security-review authenticity from bundled evidence alone; a trusted external package-root anchor and signed independent attestation remain required.

A test pass establishes only the behavior of the bound implementation under the included finite test corpus and stated local validation environment.
